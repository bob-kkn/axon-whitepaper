# Axon (AXN) Whitepaper

**The Compute Standard** — a compute-backed currency and A2A settlement ledger for the agent economy.

Axon is built on a single thesis: in an economy where most transactions run agent-to-agent, LLM compute itself becomes money. AXN is issued against verified compute supply (metered in ACU, the Agentic Compute Unit), settled on a lightweight three-layer ledger, and secured by Proof of Inference.
